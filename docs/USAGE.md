# 사용 프롬프트 모음

복사해서 `[ ]` 부분만 바꿔 쓰세요.

## 준비물

- (필수) Claude.ai: 설정 → 기능 → '클라우드에서 코드 실행' 켜기, 사용자 지정 → Skills에서 이 스킬 켜기
- (필수) 신청자 원고: 붙여 넣기 또는 DOCX·PDF·PPTX 첨부 (HWP는 PDF로 저장해서)
- (있으면 좋음) 트랙, 창업 여부, 지역, 고른 멘토기관·운영기관, 재도전 여부
- (있으면 좋음) 멘토기관 평가지표 (modoo.or.kr 기관 페이지에 공개). 넣으면 그 지표로 다시 채점해요
- (리포트 표지용) 컨설턴트 이름·소속

## 기본

```text
(파일 첨부: 신청자 도전신청서)
모두의 창업 도전신청서 검토해서 피드백 리포트 만들어줘.
신청자: [이름] / 트랙: [일반·기술 또는 로컬] / 멘토기관: [기관명]
컨설턴트: [내 이름], [소속]
```

## 상황별

### 1. 신청 전 자격·트랙 진단

```text
모두의 창업 신청하려는 분이야. 자격이 되는지, 일반/기술과 로컬 중 어느 트랙이 맞는지 봐줘.
- 아이디어: [한두 줄]
- 사업자등록: [없음 / 있음(개업일, 업종)]
- 지역: [시·도]
- 지금 받고 있는 정부 지원사업: [없음 / 사업명]
- 1차 모두의 창업 지원 이력: [없음 / 있음]
```

### 2. 초안이 없을 때: 인터뷰 질문지

```text
모두의 창업 도전신청서를 처음 쓰는 신청자야. 아이디어는 [한두 줄].
신청자가 미리 적어 올 인터뷰 질문지를 DOCX로 만들어줘. 트랙은 [로컬]이야.
```

### 3. 인터뷰 답으로 작성 설계도

```text
(파일 첨부: 인터뷰 답변 메모 또는 녹취)
이 인터뷰 답으로 문항별 작성 설계도 만들어줘. 본문은 신청자가 직접 쓸 거니까
문단 순서, 들어갈 사실, 채울 빈칸, 피할 표현 중심으로 정리해줘.
```

### 4. 멘토기관 지표로 채점

```text
(파일 첨부: 도전신청서, 멘토기관 평가지표 캡처)
이 신청서를 첨부한 멘토기관 평가지표로 채점하고 문항별 피드백 리포트 만들어줘.
2,000자 넘는 문항이 있는지도 봐줘.
```

### 5. 고친 원고 다시 보기

```text
(파일 첨부: 지난번 피드백 리포트, 고친 신청서)
지난번 피드백을 얼마나 반영했는지 비교하고 점수 변화를 보여줘. 파일 이름은 v2로.
```

### 6. 1R 진출 뒤 사업계획서

```text
(파일 첨부: 사업계획서, 받은 양식이 있으면 양식)
모두의 창업 [지역 예선 / 권역 오디션] 사업계획서야. 1R 이후 진전, 숫자 일치,
정부지원금 집행계획, 시장 규모 근거를 중심으로 검토 리포트 만들어줘.
```

### 7. 오디션 발표자료와 예상 질문

```text
(파일 첨부: 발표자료 PDF 또는 PPTX)
모두의 창업 [지역 오디션] 발표자료야. 발표 [7]분, 질의응답 [5]분이야.
장표별로 고칠 점을 알려 주고, 심사위원 예상 질문 20개와 답변 방향을 정리해줘.
```

### 8. 마감 직전 최종 점검

```text
(파일 첨부: 최종 신청서)
내일 제출할 최종본이야. 제출 직전 체크리스트로 하나씩 점검하고 글자 수도 다시 세어줘.
```

### 9. 재도전자

```text
(파일 첨부: 1차 때 낸 신청서, 이번 초안)
1차에 떨어지고 재도전하는 분이야. '1기와 달라진 점' 문항을 어떻게 쓸지 설계해 주고
이번 초안도 같이 피드백해줘.
```

## 이어서 고치기

- "Q3-1 피드백만 더 자세히 다시 해줘"
- "점수는 빼고 피드백만 있는 신청자용 리포트로 다시 만들어줘"
- "이 신청자에게 보낼 카톡 안내 문구를 리포트 요약으로 짧게 써줘"
- "확인 필요로 표시한 것만 모아서 신청자 질문 목록으로 만들어줘"
- "멘토기관을 [다른 기관]으로 바꾸면 무엇을 고쳐야 하는지 알려줘"
- "예상 질문 중 가장 어려운 5개만 골라 리허설용으로 정리해줘"

## 주의

- 이 스킬은 대신 써 주는 도구가 아니에요. "다 써줘"라고 해도 설계도와 빈칸으로 드려요.
- 점수와 등급은 공고·멘토기관 지표를 바탕으로 한 코칭용 추정이에요. 선정을 약속하는 말로 쓰지 마세요.
- 신청자가 말하지 않은 실적·숫자는 넣지 않고 `[확인 필요]`로 표시해요. 신청자에게 꼭 확인받으세요.
- 2,000자 제한은 신청 화면 기준이에요. 붙여 넣은 뒤 화면 글자 수를 꼭 다시 확인하게 하세요.
- 신청서·사업계획서에는 개인정보가 들어 있어요. 리포트 파일은 신청자 본인에게만 전달하세요.

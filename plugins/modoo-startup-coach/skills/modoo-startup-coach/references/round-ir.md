# 오디션 발표(IR) 검토 기준

지역 오디션(일반/기술 17개 지역허브 외부전문가 5인 이상, 로컬 8개 권역 공개 피칭)과 전국 오디션(전문가 → 대국민)은 발표로 평가한다. 평가 포인트는 공고 기준 **시제품 제작 결과, 향후 사업계획**(로컬은 사업화 구체화 정도 포함)이다. 전국 오디션은 대국민 평가가 섞이므로 **누구나 알아듣는 이야기**가 더 중요해진다.

발표 시간·질의응답 시간·장표 수 제한은 기관 안내마다 다르다. 반드시 신청자에게 받은 안내문으로 확인한다.

## 1. 흐름 점검 (10~15장 기준)

| 순서 | 장표 | 한 줄로 답해야 할 질문 |
|---|---|---|
| 1 | 표지 | 무엇을 하는 누구인가 (한 줄 소개 + 대표자) |
| 2 | 문제 | 누가 어떤 불편·손실을 겪나 (장면·숫자) |
| 3 | 원인·기회 | 왜 지금까지 안 풀렸고 왜 지금 풀 수 있나 |
| 4 | 해결 | 무엇을 어떻게 만들었나 (제품·서비스 사진) |
| 5 | 차별점 | 대체재와 무엇이 다른가 (비교표) |
| 6 | 증거 | 시제품·테스트·판매 결과 (가장 중요) |
| 7 | 고객·시장 | 첫 고객은 누구, 시장은 얼마나 (근거 있는 숫자) |
| 8 | 비즈니스 모델 | 누가 얼마를 어떻게 내나, 원가·마진 |
| 9 | 로드맵 | 다음 6개월·1년·3년, 무엇을 달성하나 |
| 10 | 자금 계획 | 받을 지원금을 어디에 쓰나 |
| 11 | 팀 | 왜 이 팀이 해낼 수 있나 |
| 12 | 가치·비전 | 사회·지역에 무엇이 남나 (로컬은 필수) |
| 13 | 마무리 | 한 문장 + 요청 |

한 장에 메시지 하나. 제목이 그 장의 결론이어야 한다("시장 분석" ✕ → "저당 스프레드 시장은 3년 새 37% 컸다" ○).

## 2. 장표별 점검 항목

- [ ] 제목만 읽어도 이야기가 이어진다 (제목만 모아 읽기 테스트)
- [ ] 숫자에 출처·기준 시점이 있다 (작게라도)
- [ ] 사진은 실제 현장·시제품이다 (이미지 생성물은 '이미지'라고 표시하거나 피함)
- [ ] 글씨가 너무 작지 않다 (본문 18pt 이상 권장, 표는 핵심 행만)
- [ ] '압도적', '완벽한', '혁명' 같은 말 대신 근거가 있다
- [ ] 시제품 결과에 **숫자**(테스트 몇 회, 몇 명, 만족도, 재구매 의향, 지불 의향 가격)가 있다
- [ ] 로드맵의 큰 비전(테마파크, 해외 진출)과 지금 단계 사이에 **다리**(다음 6개월 목표)가 있다
- [ ] 자금 사용 계획과 로드맵이 같은 일정이다
- [ ] 팀 장표에 각자의 역할과 이 사업에 직접 쓰이는 경력이 있다
- [ ] 마지막 장이 무엇을 기억하게 할지 분명하다
- [ ] **장표끼리 같은 숫자·이름이 같다** (시제품 개수, 면적, 금액, 브랜드명). 사업계획서 숫자와도 같다
- [ ] **이야기끼리 부딪치지 않는다** (예: '원물 100% 자가 조달' vs '인근 농가 수매로 상생')
- [ ] 이미지 결함이 없다: 투명 배경 체크무늬, 깨진 글자, 다른 회사 로고, 이미지 생성물을 실물처럼 쓴 사진
- [ ] **영업 형태와 판로가 맞다** (예: 즉석판매제조가공업은 만든 곳에서 소비자에게 직접 파는 영업이라 B2B 납품·유통은 식품제조가공업 등록이나 OEM이 필요할 수 있음 → 확인 계획)
- [ ] 로드맵에 넣은 다른 정부 지원사업이 공고의 '동시 수행 불가' 목록과 겹치지 않는지 확인했다
- [ ] 경쟁 제품을 근거 없이 깎아내리지 않았다 (성분·건강 피해 단정은 반박과 비방 시비를 부름)
- [ ] 마지막 장에 '요청' 한 줄(이번 지원으로 6개월 안에 달성할 것)이 있다

## 3. 예상 질문 은행 (범주별)

질문마다 리포트에는 '답변 방향'과 '준비할 근거'만 쓰고 답변 원고는 신청자가 쓴다.

**시장·고객**: 첫 고객은 정확히 누구인가? 그 고객에게 몇 명이나 물어봤나? 시장 규모 숫자는 어디서 나왔나? 재구매는 확인했나?
**경쟁·차별**: 대기업이 비슷한 제품을 내면? 이미 비슷한 제품이 있는데 무엇이 다른가? 따라 하기 어려운 이유는?
**원가·가격**: 원가와 판매가는? 마진은 몇 %인가? 가격은 어떻게 정했나(지불 의향 조사)?
**생산·품질**: 양산은 누가 어디서? 품질을 어떻게 유지하나? 유통기한·보관 테스트는?
**규제·인증**: 필요한 신고·인증·면허는 받았나? 일정은? (식품 영업신고·HACCP, 주류, 의료기기, KC, 개인정보 등)
**자금**: 지원금을 어디에 쓰나? 지원이 끝난 뒤 자금은? 투자 계획은?
**팀**: 혼자서(둘이서) 다 할 수 있나? 부족한 역할은 어떻게 채우나? 가족 협력의 조건은?
**지역 가치(로컬)**: 왜 이 지역이어야 하나? 지역 생산자에게 실제로 무엇이 돌아가나? 다른 지역으로 넓히면 지역성은?
**확장**: 다음 제품·시장은? 해외는 언제 어떻게? 테마파크·복합시설 같은 큰 계획의 현실성은?
**위험**: 원물 수급이 흔들리면? 가장 큰 위험 하나와 대비책은? 실패하면 무엇을 배우나?
**진정성**: 왜 이 일을 하나? 1R 이후 가장 크게 바뀐 생각은?

## 4. 자주 보이는 패턴 (로컬 오디션 발표)

강점:
- 첫 장에 대표자 얼굴과 제품, 한 줄 메시지를 함께 → 기억에 남음
- '죄책감 → 가치 소비' 같은 시장 변화의 프레임을 한 장으로
- 지역 문제(규격 미달 농산물 폐기)와 소비자 문제(클린 라벨 요구)를 교집합 그림으로 연결
- 대체재 비교표(원료·식감·원가·패키징)
- 실행 증거(생산 인프라, 수십 회 가공 테스트, 시제품 여러 종, 농가 공급망) 체크 표시
- 팀 장표에 각자의 자격·이력과 역할 분담(R&D / 생산·소싱)
- 로컬 상생 선순환 그림(농가 → 청년 기업 → 지역 사회)

보완 포인트(코칭):
- '압도적', '완벽히' 같은 수식이 근거보다 앞섬 → 테스트 수치로 대체
- 고객 반응·지불 의향(WTP) 결과 숫자가 없음 → 팝업·시식 결과를 숫자로
- 원가·마진 숫자가 없는 '원가 방어력' 주장 → 1개당 원가·판매가
- 3단계 비전(복합 테마파크, 해외)과 현재 단계의 거리 → 다음 6개월 목표를 크게
- 시장 규모·트렌드 수치 출처 없음

## 5. 리포트 구성 (모드 ⑥)

표지 → 한눈에 보기(전체 인상, 고칠 점 Top 3) → 흐름 점검표 → 장표별 피드백(장 번호 / 지금 제목 / 한 줄 메시지 / 잘된 점 / 고칠 점 / 제목 수정 방향) → 시간 배분 제안 → 예상 질문과 답변 방향 → 리허설 체크리스트 → 유의사항.

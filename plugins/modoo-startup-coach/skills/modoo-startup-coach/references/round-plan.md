# 라운드 사업계획서 검토 기준 (지역 예선·오디션 서류)

1R 진출 뒤에는 도전신청서보다 긴 사업계획서를 낸다. 양식은 차수·트랙·운영기관마다 다를 수 있으니 **신청자가 받은 양식이 우선**이다. 양식이 없으면 아래 PSST 기본 구조로 본다.

## 1. 평가 방식 다시 보기

- 일반/기술 지역 예선(8,000 → 1,000): 멘토기관 전문가 3인, **관찰식 평가(1R 프로그램 참여 과정, 책임멘토)** + **서면(사업계획서, 창업활동·멘토링 보고서)**. 멘토기관별 중점 지표.
- 로컬 지역 예선(2,000 → 1,200): 8개 권역 서면, **창업 아이디어 고도화 정도, 사업성**.
- 지역·권역 오디션: 사업화 구체화 정도, 시제품 제작 결과, 향후 사업계획 → 발표(모드 ⑥)와 함께 낸다.

즉 이 단계의 핵심 질문은 **"1R 동안 실제로 무엇을 했고, 그 결과로 무엇이 더 분명해졌나"** 이다.

## 2. PSST 기본 구조 (1차 로컬 권역 오디션 양식 예)

| 장 | 절 | 들어갈 것 |
|---|---|---|
| 1. 문제인식(Problem) | 1-1 창업 아이템의 개발 동기 | 외적 동기(사회·경제·기술 배경), 내적 동기(보유 역량, 가치관·비전) |
| | 1-2 목적 및 차별성 | 개발 목적, 아이템 소개와 개발 과정(검증된 MVP), 경쟁사·대체재 대비 우위 |
| 2. 실현가능성(Solution) | 2-1 개발 | 최종 산출물(형태·수량), 개발 방법(직접·외주), 심사 전까지 준비 단계, 창업활동자금·AI 솔루션·멘토링 활용 내역 |
| | 2-2 시장분석 및 사업화 전략 | 비즈니스 모델, 제작 방법, 창업 소요 일정, 목표 시장(TAM–SAM–SOM), 우위 요소와 차별화 전략 |
| 3. 성장전략(Scale-up) | 3-1 창업자금 소요 및 조달계획 | 정부지원금 집행계획(비목·내역·금액·비율) |
| | 3-2 기타 자본 조달 | 자기자본, 크라우드펀딩, 융자·투자 계획 |
| 4. 팀(Team) | 4-1 대표자 역량 및 역할 | 역할, 핵심 역량(증거와 함께) |
| | 4-2 외부 협력 체계 | 협력처와 역할(확정·협의·예정 구분), 향후 인력 계획 |

## 3. 점검표

### 3-1. 1R 이후 진전 (가장 중요)
- [ ] 1R 계획(도전신청서 Q4-1)에서 말한 일을 했는가? 한 일 / 못 한 일 / 바꾼 일이 구분돼 있나?
- [ ] 창업활동자금 **집행 내역**이 구체적이고 합계가 맞는가? 본문 금액과 표 합계가 같은가?
- [ ] AI 솔루션을 무엇에 써서 **무슨 결과**를 얻었나? (도구 이름 나열이 아니라 결과·결정)
- [ ] 멘토링에서 받은 조언이 **무엇을 바꿨는지** 보이는가?
- [ ] 시제품·테스트 결과가 표·사진과 함께 있고, 결과에서 내린 결정(다음 버전, 가격, 타깃)이 있는가?

### 3-2. 숫자와 근거
- [ ] 모든 합계·비율을 직접 다시 계산했다 (집행계획 합계, 비율 합 100%, 조달 합계 = 총사업비)
- [ ] 같은 숫자가 장마다 다르게 쓰이지 않았다 (예: 시장 규모, 집행액, 생산량)
- [ ] 시장 통계는 출처(기관·자료명·연도)가 있고 최근 자료다. 성장률 계산 기간이 맞다(예: 2022→2025는 3년)
- [ ] TAM–SAM–SOM의 **정의가 서로 이어지고** 계산 근거(고객 수 × 가격 × 구매 빈도 등)가 있다. TAM에 글로벌 시장을 크게 놓고 SAM을 다른 정의의 시장으로 바꾸지 않았다
- [ ] 검증 표본(시식·인터뷰·설문)의 **크기와 대상**을 밝히고, 작으면 한계를 인정했다
- [ ] 경쟁사 비교가 공정하다(우리에게 유리한 항목만 고르지 않았다). 해외 사례 수치에는 출처가 있다

### 3-3. 정부지원금 집행계획
- [ ] 비목이 해당 라운드 지원 용도에 맞다 (일반/기술 2R = MVP 제작비, 로컬 2R = 사업화자금. 세부 비목·불가 항목은 운영기관 지침 확인)
- [ ] 인건비·사업장 운영비 등 보통 지원 제외되는 비용을 자기자본으로 돌렸는가
- [ ] 비목별 금액이 일정(창업 소요 일정)과 연결된다 (언제 무엇에 쓰나)
- [ ] 외주 용역은 무엇을 맡기는지, 왜 직접 못 하는지가 보인다
- [ ] 부가세 처리: 기창업자는 부가세가 지원 대상에서 제외(로컬 공고), 1R 창업활동자금은 부가세 미환급 서약(일반/기술)

### 3-4. 실현 가능성
- [ ] 생산·제작 방법(직접·외주·OEM)과 단계 전환 시점이 있다
- [ ] 필요한 인허가·인증(식품 영업신고, HACCP, 주류 면허, 의료기기, KC, 개인정보 등)과 확인 상태가 있다
- [ ] 일정이 현실적이다(협약 기간 안에 할 일과 이후 할 일 구분)
- [ ] 협력처는 확정 / 협의 중 / 예정을 구분했다. 확정이 아닌데 확정처럼 쓰지 않았다

### 3-5. 팀
- [ ] 대표자 역량이 증거(경력·자격·한 일)와 함께 있다
- [ ] 1인 창업이면 부족한 역할을 어떻게 메우는지(외부 협력, 채용 시점) 있다
- [ ] 가족·지인 협력은 역할과 조건(공급 방식, 가격)이 분명하다

### 3-6. 표현과 진정성
- [ ] 사업계획서 자동 생성 도구 사용을 굳이 강조하지 않았다 (AI 생성률 검사가 있는 사업에서 "자동 생성 기능으로 작성"은 진정성 의심을 부른다. 쓴 도구는 '무엇을 확인하는 데 썼는지'로 쓴다)
- [ ] 상투 표현·과장어(압도적, 완벽한, 블루오션, 최초)를 근거로 바꿨다
- [ ] 그림·표만 있고 설명이 없는 곳이 없다

## 4. 자주 보이는 강점과 보완 패턴

평가자가 좋게 보는 강점 패턴:
- 외적 동기를 사회·경제·기술 배경으로 나눠 '시장 기회가 교차하는 지점'을 한 문장으로 정리했다.
- 내적 동기를 '원물 확보 → 실행력(여러 차례 시제품 실험) → 비전'으로 이어 진정성을 만들었다.
- 시제품 버전별 평가표(항목별 점수와 주요 의견)로 **개발 과정 자체를 증거**로 보였다.
- 준비 단계 표(완료 / 확보 / 진행 예정)로 지금 위치를 정직하게 보였다.
- 창업활동자금 집행 내역을 항목별 금액·비율로 공개했다.

자주 보완하게 되는 패턴(코칭 포인트):
- 본문의 집행 총액과 표 합계가 다름 → 숫자 일치 점검
- 시식 응답자 한 자릿수로 "전 연령대에서 가장 많은 선택"이라고 일반화 → 표본 한계 인정, 다음 검증(규모·방법) 제시
- 해외 경쟁사 매출 수치와 시장 규모에 출처가 약함 → 기관·자료명·연도 표기
- TAM(글로벌 시장), SAM(국내 다른 정의의 시장), 본문 통계(또 다른 시장)의 정의가 서로 다름 → 하나의 정의로 좁혀 계산
- 'AI 솔루션 활용 내역'에 사업계획서 자동 생성 도구를 넣음 → 빼거나 '무엇을 점검하는 데 썼는지'로
- 1인 팀 → 생산(OEM)·디자인·유통 협력의 확정 여부와 조건을 분명히

## 5. 리포트 구성 (모드 ⑤)

③ 도전신청서 리포트와 같은 틀을 쓰되 '문항별 피드백'을 '장·절별 피드백'으로 바꾸고, 다음 표를 더한다:
- **숫자 일치 점검표**: 항목 / 쪽·위치 / 적힌 값 / 다시 계산한 값 / 조치
- **1R 진전 점검표**: 1R 계획 / 실제 결과 / 증거 / 평가자에게 보일 방법
- **집행계획 점검표**: 비목 / 금액 / 적정성 / 의견

# 코칭용 채점 기준

> 이 기준은 공고문(평가 관점: 일반/기술 = 차별성·효과성 등, 로컬 = 창의성·지역적 가치 등)과 멘토기관 공개 평가지표, 멘토기관 안내자료(BAD & GOOD CASE)를 바탕으로 만든 **코칭용 기준**이다. 공식 배점이 아니다. 리포트에 "코칭용 추정 점수"라고 밝힌다.

## 1. 평가자 3인의 눈

일반/기술 1R은 멘토기관이 구성한 **책임멘토 3인**이 서면으로 본다. 리포트의 '평가자 한마디'는 세 사람의 시선으로 쓴다.

| 평가자 | 주로 보는 것 | 자주 하는 질문 |
|---|---|---|
| 현장·기술 멘토 | 문제의 실재, 기술·방식의 타당성, 실행 가능성 | "이게 정말 되나? 무엇을 입력받아 무엇을 내놓나?" |
| 사업·투자 멘토 | 고객, 돈 내는 사람, 시장, 확장 | "누가 얼마를 내나? 왜 지금 이 사람이?" |
| 창업 교육 멘토 | 도전의 진정성, 준비도, 성장 가능성(멘토링 효과) | "이 사람을 1R에서 도우면 2R까지 갈 수 있나?" |

## 2. 다섯 관점과 점수 기준 (각 1~5점)

### A. 문제 정의와 도전의 진정성 (WHY)
| 점수 | 기준 |
|---|---|
| 5 | 구체적인 고객·상황·장면이 있고, 신청자가 직접 확인한 근거(인터뷰·현장·경험)와 출처 있는 최신 자료가 함께 있다. 왜 지금·왜 나인지 분명하다 |
| 4 | 문제와 고객이 분명하고 근거가 있으나 직접 확인한 근거가 약하다 |
| 3 | 문제는 그럴듯하지만 일반론이 많고 근거가 한두 개, 또는 출처·연도가 불분명하다 |
| 2 | 문제가 추상적("불편하다", "비효율적이다")이거나 남의 이야기·통계만 있다 |
| 1 | 문제가 없거나 제도·정책에 대한 불만이다(심사 제외 위험) |

### B. 차별성과 혁신성 (WHAT-차별) — 로컬은 '창의성'으로 읽는다
| 점수 | 기준 |
|---|---|
| 5 | 대체재까지 비교해 차이가 분명하고, 차이가 문제 해결로 이어지는 원리가 설명된다. 따라 하기 어려운 이유(데이터·원물·네트워크·노하우)가 있다 |
| 4 | 차이가 분명하나 작동 원리나 모방 장벽 설명이 약하다 |
| 3 | 기능 차이 위주이거나 경쟁 대안 검토가 부족하다 |
| 2 | "최초·유일·경쟁사 없음" 주장 위주, 차이가 고객 가치로 연결되지 않는다 |
| 1 | 이미 있는 서비스와 거의 같다, 또는 상용화·수상 공개된 아이디어다 |

### C. 효과성과 가치 (일반/기술: 고객 가치·사회적 파급력 / 로컬: 지역적 가치)
| 점수 | 기준 |
|---|---|
| 5 | 고객이 얻는 변화가 구체적이고(시간·비용·품질 등, 실증 전이면 목표로), 사회적·지역적 파급이 근거와 함께 제시된다. 로컬은 **어떤 지역 자원**을 쓰고 **지역에 무엇이 남는지**(생산자 소득, 일자리, 상권, 관광, 폐기 감소)가 분명하다 |
| 4 | 효과가 분명하나 파급 범위나 근거가 약하다 |
| 3 | 효과가 막연하다("삶의 질 향상", "지역 활성화") |
| 2 | 고객 효과와 사회·지역 가치가 거의 없다. 로컬인데 다른 지역에서도 똑같이 할 수 있다 |
| 1 | 가치가 보이지 않는다 |

### D. 실현 가능성과 구체성 (HOW·READY)
| 점수 | 기준 |
|---|---|
| 5 | 단계별 계획에 완료 기준(숫자)이 있고, 1R 기간에 할 일이 신청자 역량·자원으로 가능하다. 필요한 협력·인허가·규제를 알고 확인 계획이 있다. 준비 과정(탐색·학습·시도)이 보인다 |
| 4 | 계획이 구체적이나 일부 단계의 완료 기준이나 자원 확보가 불분명하다 |
| 3 | 단계는 있으나 일정·기준이 막연하거나 규모가 크다 |
| 2 | "1년 내 전국, 3년 내 해외" 수준의 희망 목록, 실행 주체가 불분명하다 |
| 1 | 계획이 없다 |

### E. 사업성과 성장성 (WHAT-사업)
| 점수 | 기준 |
|---|---|
| 5 | 돈 내는 사람·상품·가격 가설·채널이 분명하고, 단계별 확장(B2B·구독·다른 품목·지역)이 앞 단계 결과와 이어진다. 가설은 가설이라 밝히고 검증 방법이 있다 |
| 4 | 수익모델이 분명하나 가격·원가·채널 근거가 약하다 |
| 3 | 수익모델 후보가 여러 개 나열돼 있고 첫 수익이 불분명하다 |
| 2 | 근거 없는 매출 전망·점유율만 있다 |
| 1 | 수익 구조가 없다 |

## 3. 가중치와 환산

| 관점 | 일반/기술 | 로컬 |
|---|---|---|
| A 문제 정의·진정성 | 20 | 20 |
| B 차별성·혁신성(로컬: 창의성) | 25 | 20 |
| C 효과성·가치(로컬: 지역적 가치) | 20 | 30 |
| D 실현 가능성·구체성 | 20 | 15 |
| E 사업성·성장성 | 15 | 15 |

환산 점수 = Σ(관점 점수 ÷ 5 × 가중치). 소수점 반올림.

**멘토기관 지표를 받은 경우**: 기관 지표(보통 3개)를 위 다섯 관점에 대응시켜 다시 묶는다. 예:
- 경희대(서울캠): 도전의 진정성 = A(+D의 준비도) / 사회적 가치 = C(+B의 독창성) / 아이디어 구체성 = D + E
- 경희대(국제캠): 문제정의 및 도전의 진정성 = A / 아이디어 경쟁력 및 확장성 = B + E / 실행·검증 가능성 및 성장잠재력 = D (+E)
기관 지표 3개를 같은 비중으로 보고 기관 지표별 점수도 함께 보여 준다.

## 4. 등급 (코칭용)

| 등급 | 점수 | 뜻 |
|---|---|---|
| A | 85 이상 | 경쟁력 있음. 세부 다듬기와 사실 확인 위주 |
| B | 70~84 | 기본은 갖춤. 약한 관점 1~2개를 보완하면 경쟁력이 생김 |
| C | 55~69 | 핵심 보완 필요. 문제 정의나 실행 계획을 다시 세워야 함 |
| D | 55 미만 | 재설계 필요. 인터뷰(모드 ②)부터 다시 |

등급은 "선정 확률"이 아니다. 같은 점수라도 멘토기관 T/O와 경쟁 상황에 따라 결과가 달라진다고 함께 적는다.

## 5. 감점 신호 (발견하면 관점 점수와 별도로 '레드 플래그'에 적는다)

멘토기관 안내자료의 BAD CASE와 공고문 유의사항:

| 신호 | 왜 문제인가 | 어디서 |
|---|---|---|
| 출처 없음 + 오래된 데이터 | 신뢰도 하락 | BAD CASE |
| 그림·도표만으로 작성(글 내용 없음) | 평가할 내용이 없음 | BAD CASE |
| 내용 1~2줄 | 성의 없음 | BAD CASE |
| 외부 자료(논문·공모전 등) 문장 그대로, AI 생성 티 | 표절·AI 생성률 검사(2기부터 강화) | BAD CASE |
| 제3자(위탁·용역) 작성 | 불법, 관련자 전원 처벌 가능 | 공고문 |
| 존재하지 않는 실적(협약·고객·팀원·매출·특허·투자) | 허위 기재 → 제외·환수 | 공고문 |
| 실증 전 확정 수치(정확도·단축률·절감률) | 과장, 신뢰도 하락 | 안내 샘플 |
| 단순 제도개선·불만 | 심사 대상 제외 | 공고문 |
| 이미 상용화되었거나 수상 이력 공개 | 선정 취소·환수 | 공고문 |
| 지원 제외 업종, 트랙 부적합 | 제외 | 공고문 |
| 법·규제 검토 없음(주류·식품·의료·금융·개인정보 등) | 실현 가능성 의심 | 안내 샘플 |
| 문항마다 고객·문제가 다름 | 일관성 없음 | 코칭 경험 |

## 6. 문항별 점수 (1~5)

문항마다 그 문항의 '평가자가 찾는 것'(`application-form.md`)을 얼마나 채웠는지로 1~5점을 준다. 5 = 다 채움, 3 = 절반, 1 = 거의 없음. 문항 점수는 관점 점수의 근거로 쓰고, 합산하지 않는다.

| 문항 | 주로 기여하는 관점 |
|---|---|
| Q1 한 줄 소개 | B, C |
| Q2 배경 | A |
| Q3-1 차별점과 문제해결 | B, C |
| Q3-2 수익창출 계획 | E |
| Q4-1 사업화 계획 | D, E |
| Q4-2 책임멘토 도움 | D (성장 가능성) |
| Q7-1 기존 사업과의 차이 | 자격(이종창업), B |
| Q8 본인 역량 | A(진정성), D(준비도) |
| Q9 팀원 | D |
| 재도전 | A, D (+가점) |

## 7. 라운드 서류(모드 ⑤)·발표(모드 ⑥)에서

같은 다섯 관점을 쓰되 무게를 옮긴다.
- 지역 예선 사업계획서: **D(1R 활동 결과·고도화 정도)와 E(사업성)** 를 더 무겁게. 일반/기술은 관찰식 평가(1R 참여 과정)가 함께 들어가므로 활동 기록·멘토링 반영 흔적이 중요하다.
- 오디션 IR: **시제품 결과(증거), 향후 계획, 발표 전달력**. 로컬은 사업화 구체화 정도.

# 진정성·사실·표현 점검 기준

## 1. 대필 금지와 컨설턴트의 선

공고문(제2026-511호) 원문:
- "사업계획서 등을 타인이 대신 작성하여 제출하는 경우, 작성자(대필자)와 도전자(대표자, 창업기업) 등 관련자 전원이 사기 또는 업무방해죄 등으로 처벌될 수 있습니다."
- "사업 신청 과정에서 제3자(컨설턴트 등)가 선정을 담보로 특정 사례를 요구하거나 접근해 온 경우" 신고 대상 (창업진흥원 누리집 > 고객광장 > 제3자 부당개입 신고, modoopolice@kised.or.kr / 소진공 bm@semas.or.kr).
- "아이디어는 도전자 본인이 직접 착안한 것만 제안할 수 있고" 표절·도용·허위가 확인되면 제외·환수.

| 해도 되는 것 (코칭) | 하면 안 되는 것 (대필·허위) |
|---|---|
| 질문으로 신청자의 경험·사실 끌어내기 | 신청자 대신 문항 본문 완성해 그대로 내게 하기 |
| 문항별 작성 설계도(메시지·순서·근거·빈칸) | 신청자가 말하지 않은 경험·숫자·실적 넣기 |
| 신청자 문장을 고쳐 보이는 짧은 예시(참고용) | 다른 사람 아이디어·자료를 각색해 주기 |
| 사실 확인표, 출처 찾는 법 안내 | "선정 보장"을 걸고 성공 보수 요구 |
| 평가 기준 설명, 체크리스트 | 신청자 계정으로 대신 입력·제출 |
| 신청 화면 사용법 안내 | 컨설턴트·가족 등 다른 사람 명의로 본인인증 (공고: 타인 정보로 인증하면 **명의자를 아이디어 제출자로 인정**) |

멘토기관 안내자료의 기준: "AI로 작성하지 마세요가 아니라 AI 초안에 나의 생각과 기술을 플러스하라." 최종 제출문은 **신청자 본인의 경험과 표현으로 한 번 더 고쳐 쓰게** 한다.

## 2. 사실 확인 규칙

- 존재하지 않는 **농가·기관 협약, 고객, 팀원, 매출, 특허, 투자유치 실적**을 만들지 않는다. (안내 샘플 제출 전 체크 2번)
- 실증 전 **AI 정확도, 개발 기간 단축률, 원가 절감률** 같은 값을 확정값으로 쓰지 않는다 → "목표", "가설", "1R에서 확인" (체크 5번)
- 협력은 **확정 / 협의 중 / 예정**으로 나눠 쓴다.
- 지역명·품종·원료·대상 등 예시용 자리표시(`[지역명]`)가 남아 있지 않은지 본다. (체크 1번)
- 이미지 분석·AI 판단을 **안전·의료·법적 최종 판단**처럼 쓰지 않는다 ("의사결정 지원"으로 한정). (체크 4번)
- 1R에서 수집할 데이터·인터뷰 수가 신청자의 시간·역량으로 가능한지 본다. (체크 6번)

## 3. 근거·출처 규칙

- 통계·시장 규모·인용에는 **(기관명, 자료명, 연도)** 를 붙인다. 가능하면 최근 2~3년 자료.
- 같은 수치를 그림 안과 본문에서 다르게 쓰지 않는다(안내 샘플의 '오류' 예: 그림의 생산량과 본문 숫자가 다름).
- 성장률 기간을 맞게 계산한다(2022→2025 = 3년).
- 논문·보고서·다른 공모전 문장을 그대로 옮기지 않는다(표절 검사). 내용을 신청자 말로 요약하고 출처를 단다.
- 출처 목록이 길면 마지막 문항이나 이미지에 정리해도 되지만, 본문에도 짧은 표기를 남긴다.

## 4. 본인 표현 점검 (AI 생성 티 줄이기)

AI 생성률 검사가 있다는 사실보다 중요한 것은 **신청자의 경험이 글에 있는가**이다. 아래 신호가 많으면 신청자에게 해당 문단을 자기 경험으로 다시 쓰게 한다.

| 신호 | 예 | 바꾸는 방향 |
|---|---|---|
| 일반론으로 시작 | "현대 사회는 빠르게 변화하고 있으며…" | 문제를 처음 본 장면으로 시작 |
| 과장·단정어 | 혁신적인, 획기적인, 압도적, 완벽한, 최초, 유일한, 세계 최고, 게임 체인저, 패러다임, 블루오션 | 근거(숫자·비교)로 바꾸거나 삭제 |
| 상투적 연결 | "단순히 ~가 아니라", "~를 넘어", "~의 새로운 지평", "시너지 극대화", "선순환 구조 구축" | 무엇이 어떻게 달라지는지 구체적으로 |
| 막연한 수식 | 다양한, 효율적인, 최적의, 스마트한, 맞춤형, 차별화된 | 무엇이 몇 개, 무엇보다 어떻게 |
| 기호·형식 | 긴 줄표(—), 쌍점(:) 남발, 영어 괄호 병기 과다 | 평범한 문장으로 |
| 같은 리듬 | 모든 문단이 '첫째·둘째·셋째', 세 항목 나열 반복, 문장 길이가 다 같음 | 중요한 것 하나를 길게, 나머지는 짧게 |
| 경험 없음 | '저는', '제가', '직접', '만나 보니' 같은 말이 한 번도 없음(배경·역량 문항) | 신청자가 한 일·본 것·들은 말을 넣기 |
| 남의 말투 | 보도자료·논문 문체 | 신청자가 평소 말하듯이 |

`check_draft.py`가 위 신호를 세어 준다. 숫자가 많다고 무조건 나쁜 것은 아니다. 문맥을 보고 판단한다.

## 5. 제출 직전 체크리스트 (모드 ⑦)

1. 자리표시(`[지역명]`, `○○`)와 예시 문구를 실제 사실로 모두 바꿨다
2. 존재하지 않는 협약·고객·팀원·매출·특허·투자 실적이 없다
3. AI·기술이 무엇을 입력받아 무엇을 예측·추천·제공하는지 한 문장으로 설명할 수 있다
4. 분석·AI 결과를 안전·의료·법적 최종 판단으로 표현하지 않았다
5. 정확도·단축률·절감률 등을 실증 전 확정값으로 쓰지 않았다
6. 1R에서 할 데이터 수집·인터뷰 규모가 내 시간·역량으로 가능하다
7. 첫 판매와 장기 사업모델의 연결이 자연스럽다
8. 관련 법적 요건(인허가·신고·인증)을 확인하겠다는 계획이 있다
9. 2,000자 제한 문항을 플랫폼에 붙여 넣고 화면 글자 수를 다시 확인했다
10. 최종 문장을 내 경험과 표현으로 한 번 더 고쳤다
11. 통계·인용에 출처(기관·자료·연도)가 있고 최신 자료다
12. 그림·표만 있고 설명이 없는 곳이 없다
13. 문항마다 같은 고객·같은 문제를 말한다
14. 트랙(일반/기술·로컬)과 멘토기관(운영기관)을 맞게 골랐다
15. 재도전자는 1차 때 가입한 수단으로 로그인했고 '1기와 달라진 점'을 썼다
16. 공개되는 내용(아이디어 자랑, 영상)에 특허 출원 전 핵심 노하우가 없다
17. 마감(16:00 정각) 2~3일 전에 제출하고 알림톡을 받았다

(1~10은 멘토기관 안내 샘플의 '제출 직전 최종 체크', 11~17은 공고문과 코칭 기준에서 더했다.)

## 6. 법·규제 확인 키워드 (규제 스크리닝)
